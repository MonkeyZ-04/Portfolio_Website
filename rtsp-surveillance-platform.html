RTSP Surveillance Platform

A full-stack surveillance platform built at SKY AI, letting operators draw interactive detection zones directly over live RTSP camera feeds.

ReactNode.jsPostgreSQLKonva.jsFFmpegGrafanaApache EChartsGoogle Apps Script
Role Data Analyst & AI Intern
Organization SKY AI
Timeline 06.2025 — 07.2025
Stack React · Node.js · PostgreSQL · Konva.js · FFmpeg · Grafana · Apache ECharts · Google Apps Script

Overview

This platform ingests live RTSP camera streams and gives operators a way to define custom detection zones on top of the video feed, rather than relying on fixed regions baked into the camera firmware. I built the full stack — from the FFmpeg-based stream handling on the backend to the interactive canvas on the frontend — plus the monitoring layer that turns raw events into dashboards people actually check.

Highlights

  • Developed a full-stack RTSP surveillance platform (React, Node.js, PostgreSQL) featuring interactive detection zones using Konva.js and FFmpeg.
  • Designed real-time Grafana dashboards to surface detection events and system health as they happened.
  • Automated data workflows using Google Apps Script and visualized trends with Apache ECharts.
