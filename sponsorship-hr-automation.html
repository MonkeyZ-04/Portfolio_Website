Sponsorship HR Automation

An HR interview web app and document automation pipeline built as Head of IT for Hill Tribe Club, streamlining sponsorship workflows for CSR fieldwork.

JavaScriptGoogle Apps Script
Role Head of IT
Organization Hill Tribe Club (CSR)
Timeline 01.2025 — Present
Stack JavaScript · Google Apps Script

Overview

Hill Tribe Club coordinates sponsorships and builds schools in remote areas, which meant a lot of manual interview scheduling and document handling. I built a web application to run HR interviews and scripted document automation on top of it, cutting down the repetitive parts of sponsorship workflows so the team could spend more time on the actual fieldwork — coordinating with local communities and provincial authorities.

Highlights

  • Engineered an HR interview web application to streamline sponsorship workflows and data collection.
  • Scripted document automation to remove repetitive manual work from the sponsorship process.
  • Coordinated field operations for building schools in remote areas, acting as a liaison between local communities and provincial authorities.
