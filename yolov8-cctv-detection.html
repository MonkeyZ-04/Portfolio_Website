YOLOv8 CCTV Detection

Human detection models deployed for CCTV monitoring at Metthier, containerized for reliability and paired with an NLP tool for text moderation.

YOLOv8DockerMQTTNLP
Role Data Science & AI Intern
Organization Metthier
Timeline 06.2024 — 07.2024
Stack YOLOv8 · Docker · MQTT · NLP

Overview

I worked on two connected problems during this internship: real-time human detection from CCTV feeds, and text-based content moderation. On the vision side, I deployed YOLOv8 models inside Docker containers so they could run consistently across different camera setups, communicating detections over MQTT for low-latency alerts. On the text side, I built an NLP tool to catch illicit terminology, and wrote the integration docs that let non-technical stakeholders work with the camera systems.

Highlights

  • Deployed YOLOv8 human detection models for CCTV monitoring via Docker containers and MQTT for real-time data communication.
  • Built an NLP tool to detect illicit terminology in text data and continuously monitored models to refine detection accuracy.
  • Authored technical documentation for Dahua camera integrations, bridging technical processes for non-technical stakeholders.
